Configure welcomes from **Settings → Welcome** in your server dashboard. A greeting can contain any combination of:

- message content;
- a Discord embed;
- a personalized image card.

You can also grant a join role. The role is independent from the greeting, so Thea can grant it even when you do not post a welcome message.

## Choose a channel

Select the channel where Thea should post. A channel is required when message content, an embed, or an image card is enabled.

Thea needs **View Channel** and **Send Messages** in that channel. Embeds and image cards have additional permission requirements described under [Delivery fallbacks](#delivery-fallbacks).

The display name set under **Settings → General** is the name shown on the post.

## Add dynamic text

Message content, embed text, and image-card text support the same placeholders:

| Placeholder | Result |
| --- | --- |
| `{user}` | A mention of the new member |
| `{username}` | The new member's Discord username |
| `{server}` | The server name |
| `{memberCount}` | The server's current member count |

Substitutions happen when the member joins. For example:

```text
Welcome to {server}, {user}! You are member #{memberCount}.
```

Only `{user}` can create a notification, and only for the person who just joined. `@everyone`, `@here`, role mentions, and other user mentions in message content remain plain text.

<Note>
  Thea checks all authored welcome text before saving it, including embed fields
  and image-card text.
</Note>

## Build a Discord embed

Turn on **Discord embed** to add structured content beside the message. You can configure:

- a title and description;
- an accent color;
- a verified author using either the server name and icon or the member name and avatar;
- a thumbnail and large image using the member avatar, server icon, or an HTTPS URL;
- up to 10 fields, with optional inline layout;
- custom footer text.

The fixed `Server welcome` suffix is appended to the footer so members can identify why the embed was posted.

## Build a personalized image card

Turn on **Personalized image card** to generate a 1200 × 480 PNG for each new member. The default card includes their avatar and uses `{username}`, `{server}`, and `{memberCount}` in its text.

You can change:

- the centered, split, or banner layout;
- circle, rounded, or square avatar shape;
- Inter, Poppins, or Roboto Slab font;
- overlay opacity;
- accent, text, and fallback background colors;
- card title and message;
- whether the card appears as a message attachment or inside the embed.

The dashboard preview uses the current server and your signed-in Discord account as sample data. Discord's final rendering can differ slightly.

### Choose a background

<Tabs>
  <Tab title="Built-in preset">
    Choose Midnight, Aurora, Sunset, or Ocean. Presets are generated by Thea and
    do not download an external image.
  </Tab>

  <Tab title="HTTPS URL">
    Enter a public `https://` image URL. Thea checks redirects, host safety, file
    type, download size, and decoded pixel count before saving it.
  </Tab>

  <Tab title="Upload">
    Upload a PNG, JPEG, or WebP image up to 8 MB. Thea checks the decoded image,
    crops it to the card dimensions, and stores a normalized WebP background.
  </Tab>
</Tabs>

Animated images and vector files are not supported. Raster images must be under 24 megapixels.

<Warning>
  Uploaded welcome backgrounds are public. The normalized background is stored
  at a public URL because it is used in images posted publicly to Discord. Do
  not upload private or sensitive material.
</Warning>

## Delivery fallbacks

The greeting parts fail independently:

- Without **Embed Links**, Thea omits the Discord embed. A generated card can still appear as a normal attachment.
- Without **Attach Files**, Thea omits the generated card but can still send message content and an embed.
- If card generation or a remote background fails, message content and the embed can still be delivered.
- If Thea cannot send to the selected channel, the join role can still be granted.

Thea limits welcome posts to 10 per server per minute during a join surge. Additional greetings are skipped, but eligible join roles are still granted.

## Join role safety

Choose an optional role to grant when a member joins. Thea refuses `@everyone`, integration-managed roles, roles at or above its highest role, and roles with moderation permissions.

The role is checked again on every join. If somebody later makes the role unsafe or moves it above Thea, it is not granted.

## Raid protection

While [raid protection](/moderation/raid-protection) holds a newcomer behind the challenge gate, Thea sends no greeting and grants no join role. Both are delivered after that newcomer passes verification.

Thea does not greet established members again when they complete a challenge. [Onboarding reminders](/dashboard/onboarding-forms) also remain paused while raid mode is active.

## Discord commands

Rich visual editing stays in the dashboard. Discord commands provide quick controls and a summary:

```text
/config welcome show
/config welcome set channel:#general message:Welcome {user}
/config welcome set role:@Member
/config welcome off
```

- `show` summarizes the current message, embed, card, channel, and join role, then links to the dashboard editor.
- `set` changes the channel, plain message content, or join role. It does not expose the visual builder.
- `off` clears the welcome channel, message content, embed, image card, and join role.

## Backups and cloning

[Configuration backups](/dashboard/backup-and-clone) include the message, embed, and card settings. Uploaded backgrounds are exported as their public HTTPS URL, so a clone never receives ownership of another server's stored object.

## Troubleshooting

### Nothing is posted

Confirm that:

1. a welcome channel is selected;
2. at least one of message content, Discord embed, or personalized image card is enabled;
3. Thea can view and send messages in the channel;
4. raid mode is not holding the member for verification.

### The embed or image is missing

Check **Embed Links** for embeds and **Attach Files** for generated cards. If you use a URL background, confirm that it is still publicly reachable over HTTPS.

### The join role is not granted

Move Thea's highest role above the join role and remove moderation permissions from the join role. `/config welcome show` reports when the saved role is no longer safe.
