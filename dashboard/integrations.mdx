Integrations pull knowledge from tools you already write in. They are available on **Pro** and **Business**. Each connection counts as **one** knowledge source, even if it contains hundreds of pages.

Upgrade from that server's **Billing** page.

## Connect Notion

<Steps>
  <Step title="Create a Notion integration">
    In Notion, create an internal integration at [notion.so/my-integrations](https://www.notion.so/my-integrations) and copy its token (it starts with `ntn_`).
  </Step>
  <Step title="Share pages with it">
    Share the pages you want indexed with that integration. Thea can read only those pages. Share more pages later to add them.
  </Step>
  <Step title="Connect it in Thea">
    Go to **Knowledge → Add source → Connect platform**, choose **Notion**, paste the token, and click **Connect and sync**.
  </Step>
  <Step title="Wait for Ready">
    The first index starts immediately. Later syncs follow your plan: every **24 hours** on Pro, every **6 hours** on Business.
  </Step>
</Steps>

## Connect Zendesk

<Steps>
  <Step title="Open Knowledge">
    **Knowledge → Add source → Connect platform**, then choose **Zendesk**.
  </Step>
  <Step title="Enter your subdomain">
    The part before `.zendesk.com`. This works with any public Zendesk help center, so no credentials are needed.
  </Step>
  <Step title="Connect and sync">
    Click **Connect and sync**.
  </Step>
  <Step title="Confirm the index">
    Check passage count and last sync on **Knowledge**.
  </Step>
</Steps>

Choose **Re-sync** from a connection's menu to sync it now. Thea redacts values that look like credentials from synced pages and shows a **credentials** badge on the source. See [Credentials in your docs](/answering/knowledge-sources#credentials-in-your-docs).

## Content API

For docs the crawler cannot reach, push Markdown with an API key. Full request shapes, errors, and examples: [Content API](/dashboard/content-api).

Keys are created on **Settings → API**. Only the owner can create or revoke them. The full secret is shown once. Notion, Zendesk, and the API source each count as one source toward the plan cap (25 on Pro, 200 on Business).

<Warning>
  API keys can read and write this server's external pages. Store them in a secrets manager and revoke them if they leak or if the person who created them leaves.
</Warning>
