**Audit** records configuration changes on this server: who changed what, when, and any metadata the action attached. Open it from the server sidebar. You need admin-level dashboard access.

Typical entries include settings saves, API key create/revoke, Content API writes, imports from [Backup & clone](/dashboard/backup-and-clone), and collaborator changes.

The audit log is not automatically pruned.

## Exports

| Export | Where | Contents |
|---|---|---|
| **Export audit log** | **Audit** | Configuration changes, exports, and enforcement recorded against this server |
| **Export findings** | **AutoMod → Export** | Manual commands and AutoMod actions. This is the same ledger `/record` and `/standing` read from. |
| **Export review outcomes** | **AutoMod → Export** | Moderator rulings on findings |

Use the AutoMod exports for ban appeals, shift handoff, or an external compliance request.

Each server can run 5 exports an hour, shared between the audit log and AutoMod exports. A date range can cover up to 366 days. If an export is refused, the page shows why instead of downloading a file.

<Note>
  Message bodies are not in these exports. Server logs post content to Discord
  only. AutoMod stores hashes for repeat-offender correlation, not raw text.
  Optional network records use keyed indicator digests rather than raw URLs or
  server identities. See [Scam Defense Network](/moderation/scam-defense-network),
  [Server logs](/community/server-logs), and
  [Privacy](https://www.theabot.com/privacy).
</Note>
