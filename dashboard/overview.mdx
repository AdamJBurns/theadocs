Each Discord server has its own isolated dashboard: its own knowledge, AutoMod, tickets, and plan. Switch servers from the selector. Account-level pages (all servers, billing overview, [account standing](/account/standing)) live under `/servers`.

## Server navigation

### Monitor

| Page | What it is |
|---|---|
| **Overview** | Setup checklist, plan usage, health, recent conversations |
| **Activity** | Charts for answers, declines, and AutoMod over 7 or 30 days |
| **Stats** | Live Discord counts — members, boosts, channels, verification level |
| **Conversations** | Every question Thea handled. See [Conversations](/answering/conversations) |
| **Tickets** | Queue, CSAT, transcripts. See [Tickets](/tickets/overview) |

### Build

| Page | What it is |
|---|---|
| **Knowledge** | Sources and gaps. See [Knowledge sources](/answering/knowledge-sources) |
| **Help Center** | Articles and collections. See [Help center](/help-center/overview) |
| **Playground** | Rehearse answers. See [Playground](/answering/playground) |

### Admin

| Page | What it is |
|---|---|
| **Announcements** | Scheduled posts. See [Announcements](/community/announcements) |
| **Scam defense** | Live scam signals and effective policy. See [Scam defense](/moderation/scam-defense) |
| **AutoMod** | Opens **Settings → AutoMod** |
| **Members** | Dashboard collaborators, when the beta is on. See [Collaborators](/dashboard/collaborators) |
| **Audit** | Configuration history. See [Audit](/dashboard/audit) |
| **Settings** | The cards below |
| **Billing** | This server's plan. Owner only. See [Plans and billing](/plans-and-billing) |

## Weekly digest

**Settings → General → Weekly digest** posts a short summary — answers, tickets, escalations, AutoMod — to a staff channel you pick. It is a Discord message, not an email. Each digest uses one AI summarization.

## Overview checklist

Until the server is fully set up, Overview walks through:

1. Add a knowledge source
2. Let it index
3. Choose where the bot answers
4. Route escalations
5. Get a first answer in Discord or the Playground
