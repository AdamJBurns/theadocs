The Thea dashboard is where everything comes together. From here you monitor how your bot is performing, manage the knowledge it draws on, configure AutoMod and ticket handling, test changes before they go live, and adjust every setting that governs Thea's behavior in your server. Each section is purpose-built for a specific part of running a Thea-powered community.

## Dashboard sections

<CardGroup cols={2}>
  <Card title="Workspace / Overview" icon="house">
    Server health at a glance: total answers given, current escalation rate, active tickets, and a summary of recent AutoMod activity. Start here when you log in to get a quick pulse on your community.
  </Card>
  <Card title="Conversations" icon="messages">
    A full log of every question Thea has answered or escalated. Each entry shows the member's question, the answer or escalation reason, the confidence score, and the exact source passages cited. Use this to audit quality and spot gaps.
  </Card>
  <Card title="Tickets" icon="ticket">
    View open, claimed, overdue, and closed tickets in one place. Assign tickets to staff, update status, and download full conversation transcripts for any ticket — useful for compliance, training, or dispute resolution.
  </Card>
  <Card title="Knowledge / Sources" icon="book">
    Manage every connected knowledge source. Add new sources, remove outdated ones, trigger a manual re-sync on any source, and see the total number of indexed passages per source. This is your single source of truth for what Thea knows.
  </Card>
  <Card title="Playground" icon="flask">
    Test any question against your live knowledge base before it reaches Discord. See exactly which passages Thea would cite, the confidence score it would assign, and whether it would answer or escalate. Run a question set before launching a new knowledge source.
  </Card>
  <Card title="Guardrails" icon="shield">
    Set the confidence threshold below which Thea escalates instead of answering, choose the escalation role, apply tone presets, and define scope rules that limit Thea to topics relevant to your community.
  </Card>
  <Card title="AutoMod" icon="ban">
    Configure each moderation layer: Discord-native rules, spam and scam-link heuristics, the moderation API, and the AI pass. Set severity actions, build a repeat-offender ladder, and review flagged content in the review queue.
  </Card>
  <Card title="Settings" icon="gear">
    General server settings, billing and plan management, notification preferences, and tools to back up or restore your entire Thea configuration.
  </Card>
</CardGroup>

## Multi-server management

If you manage more than one Discord server, each server gets its own isolated dashboard workspace — separate knowledge bases, separate AutoMod rules, and separate ticket queues. Switch between workspaces using the server selector in the top-left corner of the dashboard. Billing is consolidated at the account level, so you manage your subscription and payment method in one place regardless of how many servers you run.

## Back up and clone your configuration

From **Settings → Backup & Restore**, export your entire Thea configuration — knowledge sources, guardrail settings, AutoMod rules, ticket routing, and onboarding form setup — as a single JSON file. Import that file into another server's dashboard to clone the configuration instantly. This is useful when launching a second community with the same structure, or when you want a staging server that mirrors your production setup.

<Tip>
  Press **G** then a section key (shown in the sidebar tooltips) to jump directly to any dashboard section without using the mouse — handy for staff who live in the dashboard during busy periods.
</Tip>
