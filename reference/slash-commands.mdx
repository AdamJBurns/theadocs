Commands that change server configuration require **Manage Server** unless noted. Moderator actions follow Discord's own permissions (Moderate Members, Kick Members, Ban Members, Manage Messages, Manage Roles). Each handler also checks permissions on the server — hiding a command in the picker is not the security boundary.

For invite and `/setup`, see [Discord setup](/dashboard/discord-setup).

## Setup and config

| Command | Who | What it does |
|---|---|---|
| `/setup` | Manage Server | Set the watched channel and optional support role |
| `/source add` | Manage Server | Add a knowledge URL |
| `/source list` | Manage Server | List sources |
| `/config show` | Manage Server | Print current answering settings |
| `/config set` | Manage Server | Set trigger, threshold, persona, escalation, support role, or ticket SLA |
| `/config export` | Manage Server | Link to the dashboard [backup download](/dashboard/backup-and-clone) |
| `/config welcome show\|set\|off` | Manage Server | [Welcome](/community/welcome) |
| `/config logging show\|channel\|event` | Manage Server | [Server logs](/community/server-logs) |
| `/status` | Manage Server | Usage, limits, and whether answering is paused |

## Answering

| Command | Who | What it does |
|---|---|---|
| `/ask` | Any member | Private ephemeral question. Uses your knowledge, threshold, and answer quota. |
| `/standing` | Any member | Own [member standing](/moderation/standing). Staff can pass a user. |

## Tickets

`/ticket` is available to members for `open`. The rest are staff actions. See [Tickets](/tickets/overview).

| Subcommand | What it does |
|---|---|
| `setup` | Enable tickets and post the panel |
| `open` | Open a ticket (same as the panel button) |
| `close` | Close the current ticket |
| `claim` / `unclaim` / `assign` | Ownership |
| `note` | Internal staff note |
| `reopen` | Reopen a closed ticket |
| `disable` | Turn tickets off |
| `fields add\|remove\|list` | Open-time form questions |

## Onboarding

| Command | What it does |
|---|---|

See [Onboarding forms](/dashboard/onboarding-forms).

## AutoMod and raid

| Command | What it does |
|---|---|
| `/automod show` | Current AutoMod settings |
| `/automod test` | Simulate a message against live rules |
| `/automod enable` / `disable` | Master switch |
| `/automod rules` | AI rules text |
| `/automod exempt` | Exempt roles or channels |
| `/automod log-channel` | Review / action log |
| `/automod action` | Per-severity actions |
| `/automod escalation` | Repeat-offender ladder |
| `/automod topic` | [Channel focus](/moderation/automod) |
| `/raid on` / `off` / `status` | Raid mode |
| `/raid set` | Thresholds and duration |
| `/raid exempt` | Roles the gate skips |
| `/raid verify` / `deverify` | Mark a member as having passed or reset them |

## Moderator actions

These write to the same ledger as AutoMod. See [Moderator commands](/moderation/moderator-commands).

| Command | Discord permission | What it does |
|---|---|---|
| `/warn` | Moderate Members | DM the member and record a warn |
| `/timeout` | Moderate Members | Duration like `10m`, `2h`, `3d` (max 28 days) |
| `/untimeout` | Moderate Members | Lift a timeout |
| `/kick` | Kick Members | Remove the member |
| `/ban` | Ban Members | Permanent or for a number of days; optional message purge |
| `/unban` | Ban Members | Lift a ban |
| `/softban` | Ban Members | Ban then unban to delete about a day of messages |
| `/purge` | Manage Messages | Delete 2–100 recent messages, optional user filter |
| `/record` | Moderate Members | Show a member's moderation record |
| `/delwarn` | Moderate Members | Remove the latest manual warn |
| `/moderations` | Moderate Members | Temporary bans waiting to lift |
| `/note` / `/notes` / `/delnote` | Moderate Members | Private staff notes on a member |
| `/watch` / `/unwatch` | Moderate Members | Watchlist — closer scrutiny, optional expiry. Max 200 watches per server. |
| `/lock` / `/unlock` | Manage Roles | Lock or unlock the channel, optional notice |

## Context menu

**Report to bot operator** (right-click a message) sends a report to Thea staff, not your server moderators. Rate limit: 3 reports / 10 minutes / member / server.
