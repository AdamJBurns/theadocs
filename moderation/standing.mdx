Every AutoMod finding on a server is recorded on that member's **standing**. So is every moderator action taken through Thea, such as `/warn`, `/timeout`, `/kick`, and `/ban`. Members can check their own record with `/standing`.

This is per-server. It is not the same as [account standing](/account/standing), which is Thea's platform ledger for the person who signed in to the dashboard.

## Check standing

```
/standing
```

The reply is ephemeral and only ever describes the member who ran it. There is no option to look up someone else. Staff use [`/record`](/moderation/moderator-commands) for that.

The reply shows:

- Findings from the escalation window, newest first, with the date, the category, and the action taken. The first eight are listed, then a count of the rest.
- When the oldest counted finding stops counting.
- If repeat-offender escalation is on, each step, with an arrow on the step the member has reached, and how many findings away the next step is.

Findings a moderator approved on review are off the record and do not appear.

## What counts

`/standing` reads the record the same way repeat-offender escalation does.

| Finding | Listed | Counts toward escalation |
|---|---|---|
| Warnings, held messages, removals, timeouts, kicks, and bans | Yes | Yes |
| Findings that were only logged, with no action taken | Yes | No |
| Off-topic warnings from [Channel focus](/moderation/automod#channel-focus) | Yes | No |

When some listed findings do not count, the reply says how many of them count.

Kicks and bans from other servers, global-blacklist listings, and platform account standing do **not** appear here.

## How long findings count

A finding counts for the escalation window you set, from 1 to 90 days. Without a repeat-offender rule, `/standing` looks back 30 days. After the window, that finding no longer counts toward escalation.

## Repeat offenders

**Settings → AutoMod → Repeat offenders** raises the action when a member accumulates enough findings in a window you set. The count uses AutoMod's event log. Message content is never stored — only a hash used to correlate repeats.

Configure the ladder there, or with `/automod escalation`. Repeat-offender escalation can raise an action. It never lowers one.

See [AutoMod](/moderation/automod) for the full action list.
